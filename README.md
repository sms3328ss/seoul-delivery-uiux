# 서울배송

수업용 가상 배송 안내 페이지입니다. 실제 업체·운영 서버와 연결하지 않습니다.

1~7주차 요구사항을 순서대로 다시 구성하는 보완 작업이며 커밋 날짜는 실제 작업일입니다.

## 현재까지 구현
- 1주차: 첫 HTML 페이지와 공개 저장소를 준비했습니다.
- 2주차: HTML 주석으로 사용자와 목적을 적고, 주요 기능 3개·이용 방법 3단계·이미지와 대체 텍스트·입력 영역·내부 이동을 구성했습니다.
- 3주차: CSS를 연결해 글자·배경·테두리·여백과 영역 구분을 적용했습니다.
- 4주차: Grid와 유동 너비, 768px 이하 세로 배치를 추가했습니다.
- 5주차: 이메일의 빈 값·잘못된 형식·정상 입력을 구분하고 안내 스타일과 확인 버튼 상태, 수정·초기화를 구현했습니다.
- 6주차: 3개 탭과 click·input·change 이벤트를 연결했습니다. 요청 사항 글자 수와 배송 종류 안내가 달라집니다.
- 7주차: 시작·입력과 선택·확인·완료 흐름을 연결했습니다. 필수값 검사, 이전 값 유지와 수정 반영, 다시 시작 초기화를 구현했습니다.

배포 설정과 최종 테스트 기록은 누적 구현 후 갱신합니다.
